# 创新统计方法

## 适应性设计 (Adaptive Design)

### 定义

允许在试验进行中，根据累积数据对试验的一个或多个方面进行修改的设计方法。

### 常见适应性元素

| 适应性类型 | 描述 | 优势 |
|------------|------|------|
| **样本量再估计** | 基于中期方差或效果量调整样本量 | 避免样本量不足或过度招募 |
| **无效终止** | 中期分析显示无效时提前终止 | 节省资源，减少患者暴露于无效治疗 |
| **优效终止** | 中期分析显示优效时提前终止 | 提前获益，加速审批 |
| **剂量选择** | 淘汰无效剂量组 | 聚焦最有希望的剂量 |
| **人群富集** | 基于生物标志物富集响应人群 | 提高检验效能 |

### 统计挑战

| 挑战 | 解决方案 |
|------|----------|
| I 类错误控制 | 组合检验统计量、条件错误函数 |
| 估计偏倚 | 无偏估计量、bootstrap 校正 |
| 操作偏倚 | 独立数据监查委员会 (IDMC) |
| 结果解释 | 预先定义适应性规则，透明报告 |

## 贝叶斯方法 (Bayesian Methods)

### 贝叶斯剂量探索

**Emax 模型**:

```
E(d) = E0 + (Emax × d^γ) / (ED50^γ + d^γ)
```

| 参数 | 含义 |
|------|------|
| E0 | 基线效应 |
| Emax | 最大效应 |
| ED50 | 达到 50% 最大效应的剂量 |
| γ | Hill 系数 (曲线陡峭度) |

### 贝叶斯优势

- 可以利用先验信息（临床前数据、同类药物）
- 提供直观的概率解释
- 适合复杂模型和小样本

### 决策规则示例

```
- P(剂量最优 | 数据) >0.90 → 选为推荐剂量
- P(严重不良事件>阈值) <0.10 → 安全性可接受
```

## 多臂多阶段设计 (MAMS)

### 特点

- **多臂**: 同时评估多个治疗
- **多阶段**: 中期分析淘汰无效臂
- **共享对照**: 提高效率
- **平台试验**: 可动态添加新臂

### 优势

| 优势 | 说明 |
|------|------|
| 效率高 | 共享对照组，减少总样本量 |
| 灵活 | 可添加新治疗臂 |
| 快速 | 无效治疗提前淘汰 |

### 案例：STAMPEDE 试验

**设计**: 三臂平行组
- 强化药物治疗
- Roux-en-Y 胃旁路术
- 袖状胃切除术

**结果**: 手术显著优效于药物 (P<0.001)

## 负二项分布 (Negative Binomial)

### 适用场景

- 心衰住院 (可重复发生)
- 急性肾损伤事件
- 低血糖事件

### 模型公式

```
log(E[Y]) = log(follow-up time) + Treatment + Covariates
Y ~ Negative Binomial(μ, θ)
```

### 优势

| 优势 | 说明 |
|------|------|
| 利用所有事件 | 不仅首次事件，信息更充分 |
| 更高检验效能 | 相比时间 - 事件分析 |
| 处理过度离散 | 通过θ参数处理个体差异 |

### 案例：CREDENCE 试验

- 主要终点：肾病复合 (时间事件)
- 次要终点：重复心衰住院 (负二项)
- 结果：心衰住院率比=0.61 (95%CI: 0.46-0.80)

## MMRM (混合效应重复测量模型)

### 适用场景

- 纵向连续变量 (如 HbA1c 多次测量)
- 处理缺失数据 (假设 MAR)

### 模型设定

```
Y_ijk = μ + Treatment_i + Country_j + Visit_k 
        + Treatment×Visit_ik + Baseline_covariate 
        + Participant_random_effect + ε_ijk
```

### 关键假设

- **MAR (随机缺失)**: 缺失概率仅依赖于观测到的数据
- 需进行敏感性分析验证假设稳健性

## 总结

| 方法 | 适用场景 | 关键优势 |
|------|----------|----------|
| 适应性设计 | II/III 期试验 | 灵活、高效 |
| 贝叶斯方法 | 剂量探索、小样本 | 利用先验、直观解释 |
| MAMS | 多治疗比较 | 共享对照、快速淘汰 |
| 负二项分布 | 重复事件 | 利用全部信息 |
| MMRM | 纵向数据 | 处理缺失、效率高 |
