# 糖尿病试验 Estimand 案例

## AWARD-10 研究 (NCT02597049)

### 研究设计概要

| 项目 | 详情 |
|------|------|
| **研究名称** | AWARD-10 |
| **Sponsor** | Eli Lilly and Company |
| **研究设计** | 24 周、随机、双盲、安慰剂对照、平行组 IIIb 期研究 |
| **纳入人数** | 424 名患者 |
| **治疗组** | Dulaglutide 1.5mg QW / 0.75mg QW / Placebo QW |
| **背景治疗** | SGLT2 抑制剂 ± 二甲双胍 |
| **主要终点** | 24 周 HbA1c 较基线变化 |

### 双 Estimand 策略

AWARD-10 研究定义了**两个互补的 Estimand**，分别回答不同的临床问题：

#### Estimand 1: Treatment-regimen Estimand

| 要素 | 定义 |
|------|------|
| **研究问题** | "实际接受的治疗方案效果如何？" |
| **目标人群** | 所有随机化患者（ITT 人群） |
| **终点变量** | 24 周 HbA1c 测量值（无论是否使用救援药物） |
| **处理策略** | **包含救援后数据** |
| **群体水平汇总** | MMRM 模型的最小二乘均值 (LS Mean) |

**临床解释**: 回答"在临床实践中，起始 Dulaglutide 治疗方案（允许后续救援）的实际效果如何？"

#### Estimand 2: Efficacy Estimand

| 要素 | 定义 |
|------|------|
| **研究问题** | "随机分配的治疗在按指示服用时的效果如何？" |
| **目标人群** | 所有随机化患者（ITT 人群） |
| **终点变量** | 24 周 HbA1c 测量值（**排除救援后数据**） |
| **处理策略** | **排除救援后数据** |
| **群体水平汇总** | MMRM 模型的最小二乘均值 (LS Mean) |

**临床解释**: 回答"如果没有救援药物干扰，Dulaglutide 本身的生物学疗效如何？"

### 救援药物规则

| 时间点 | 救援标准 |
|--------|----------|
| **任何时间** | FPG >270 mg/dL (>15.0 mmol/L) |
| **Week 5 后** | FPG >240 mg/dL (>13.3 mmol/L) |
| **Week 9 后** | FPG >200 mg/dL (>11.1 mmol/L) |

**救援措施**: 开放标签的胰岛素或其他降糖药物

## CVOT 试验 Estimand 案例

### EMPA-REG OUTCOME (NCT01131676)

**Estimand 定义**:

| 要素 | 定义 |
|------|------|
| 人群 | 随机化的所有患者 (ITT 人群) |
| 变量 | 首次发生 MACE-3 的时间 |
| 策略 | 治疗策略型 (无论是否停药，数据均纳入) |
| 汇总 | 风险比 (HR) 及 95%CI |
| 截断事件 | 失访、撤回同意、研究终止 |

**结果**:
- MACE-3 HR=0.86 (95%CI: 0.74-0.99, P=0.04 优效)
- 心血管死亡 HR=0.62 (95%CI: 0.49-0.77, P<0.001)

### LEADER 试验 (NCT01179048)

**Estimand 定义**:

| 要素 | 定义 |
|------|------|
| 人群 | 随机化并接受至少一剂药物的患者 (mITT) |
| 变量 | 首次 MACE-3 发生时间 |
| 策略 | 治疗策略型 (无论是否停药) |
| 汇总 | HR 及 95%CI |
| 截断事件 | 失访、撤回同意、研究结束 |

**结果**:
- MACE-3 HR=0.87 (95%CI: 0.78-0.97)
- P<0.001 非劣效，P=0.01 优效

## Estimand 选择指南

| 临床问题 | 推荐 Estimand 类型 | 干扰事件策略 |
|----------|-------------------|-------------|
| 注册审批（主要疗效） | Efficacy Estimand | 排除救援后数据 |
| 临床实践指导 | Treatment-regimen Estimand | 包含所有数据 |
| 卫生经济学评估 | Treatment-regimen Estimand | 包含所有数据 |
| 机制研究 | Efficacy Estimand | 排除救援后数据 |
